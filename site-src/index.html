Browser-only pseudo terminal

给静态站点和博客使用的可插拔伪终端

Shell、VFS、命令插件、渲染器和持久化相互独立。你可以把它做成博客彩蛋、文档沙箱、CTF 练习环境或自己的站点终端。

Extension model

扩展时只需要替换你关心的层

加命令

通过 `terminal.register()` 注册命令，返回 `stdout`、`stderr`、`status` 和 `events`。

加文件系统

用 VFS API 添加目录、文章、CTF 线索、配置文件和只读资料。

换外观

默认 DOM 渲染器可以直接用，也可以替换成浮窗、全屏、横幅或框架组件。

换终端生态

内置 Windows 风格插件，可以改造成 PowerShell 或 CMD 风格终端。

接博客文章

可读取 RSS/Atom，也能从页面 feed link 自动发现文章来源。

中断长命令

异步命令支持超时和 AbortSignal，渲染器可实现运行中 Ctrl+C。

控安全边界

真实命令执行、网络访问和包安装默认关闭，危险命令在命令层和 VFS 层双重阻止。

import { createTerminal, ok } from 'termlet';

function myPlugin(terminal) {
  terminal.register('hello', ({ user }) => ok(`hello ${user}\n`));
}

const terminal = createTerminal({
  plugins: [myPlugin],
});

Deployment

一个仓库就能托管文档和在线演示

1 推送当前仓库到 GitHub。

2 在仓库 Settings → Pages 中选择 GitHub Actions。

3 推送到 `main` 或 `master` 后，workflow 会构建 `site/` 并发布。

npm run verify
npm run site:build
