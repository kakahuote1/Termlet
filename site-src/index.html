Browser-only terminal kit

把伪终端插进任何静态站点

Termlet 提供一个安全的前端终端基座：Shell 解析、虚拟文件系统、命令插件、终端渲染器和主题都可以自由组合。

Linux sandbox · guest@demo:~ ready

Same core, different shells

同一个基座，可以切换不同终端

下面不是截图，都是浏览器里运行的 Termlet 实例。外观、prompt、命令集、主题和文件系统都能独立配置。

PowerShell 风格

createWindowsTerminal({ shell: 'powershell' })

提供 Get-Location、Get-Item、Test-Path、Set-Content 等 Verb-Noun 命令，也支持对象管道。

CMD 风格

createWindowsTerminal({ shell: 'cmd' })

提供 dir、type、copy、del 等 CMD 命令，并可保留 ls、cat 等常用兼容命令。

Composable parts

可随心修改的终端基座

命令插件

用 command pack 组合命令集，用 `register()` 加命令，也可以返回 disposer 清理插件。

结构化管道

命令可以返回对象数组，后续命令用 `input` 继续过滤、排序、投影和渲染。

虚拟文件系统

文章、线索、配置、只读文件都能映射进去，不会碰真实机器。

主题与渲染器

默认 DOM renderer 可以直接用，也可以换成弹窗、横幅、全屏或框架组件。

博客适配

支持 Hugo，也支持通用 RSS/Atom feed，把文章变成终端里的文件。

安全边界

不连真实 shell，不执行用户代码；危险命令只在模拟层失败。

Drop-in usage

三步接入博客

下载构建产物，把 `dist/` 改名为 `termlet/` 放进站点静态目录，再复制下面这段 HTML。Hugo、Hexo、Jekyll、Astro、VitePress 都是同一个思路。

下载 drop-in zip

压缩包里已经包含 `index.html` 和 `termlet/`，解压后可以直接放进静态站点测试。

1

运行 `npm run build`，或下载 release 里的 `dist/`。

2

把 `dist/` 复制到博客静态目录，并改名为 `termlet/`。

3

粘贴代码，修改 `siteName`、`intro` 和 `theme`。

<link rel="stylesheet" href="/termlet/termlet.css">
<div id="terminal"></div>
<script type="module">
  import { mountStarterTerminal } from '/termlet/index.mjs';

  await mountStarterTerminal({
    mount: '#terminal',
    injectStyles: false,
    theme: 'linux',
    siteName: 'My Blog',
    intro: 'Welcome to my terminal.',
  });
</script>

Built-in themes

换一个词就能换主题

`theme` 支持 linux、powershell、cmd、light、crt。需要更细的外观时，覆盖 `--termlet-*` CSS 变量即可。
